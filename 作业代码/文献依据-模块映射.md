## 二、模块 → 方法 → 文献 映射

### M1 信号建模（`part1_M1_信号建模/`）

| 实现内容 | 方法 | 文献 | 支撑点 |
|---|---|---|---|
| 遥控链路 | **FHSS + GFSK**（BT=1.0，h=0.5，64 信道） | #1 #6 | 实测遥控为跳频+调制数据，非纯载波 |
| 图传链路 | OFDM（52 子载波，CP=16/64，QPSK） | #1 #2 | 实测图传为宽带 OFDM 突发 |
| 导航信号 | GPS L1 C/A（Gold 码，1.023 Mchip/s） | #9 #1 | 无人机导航依赖 C/A 码 |
| 信道与损伤 | 时变多径 + CFO + 多普勒 + 相噪 + IQ 不平衡 + 非线性 + AWGN | #1 #2 #3 #7 | 实测信号非理想：误差底、频偏、多径 |

**关键改进（相对初版"过于理想"）**：
1. 遥控链路由**纯 CW 载波**改为 **GFSK 调制**（文献依据 #1 #6）；
2. 新增接收机损伤链，产生**误差底**（高 SNR 下性能不再无限提升），符合实测；
3. BT 由 0.5 改 1.0：BT=0.5 脉冲跨 ~4 符号，朴素接收机下无噪误码达 24%，
   BT=1.0 对应低成本 FHSS 遥控接收机的真实工作点。

## 四、报告与 PPT 引用建议

**必引（核心 5 篇）**：#1 RFUAV、#2 DroneRFa、#4 低 SNR CNN、#9 GNSS 干扰欺骗综述、（M5 起）#11 SemperFi

**分章引用**：
- 引言： #7 综述、#8 ML 综述
- 第 2 章 信号建模： #1 #2 #3 #6
- 第 3 章 特征分析： #1 #5 #7
- 第 4 章 电子侦察： #4 #5 #6 #8 + Tandra&Sahai
- 第 5 章 电子干扰： #9 #10 #14
- 第 6 章 电子反干扰： #11 #12 #13 #14
- 第 7 章 结论与展望： #1（数据集实测验证）、#14（RL 在线干扰策略）

**答辩亮点**：
1. 「一套特征支撑三线」的主线（特征分析→侦察→干扰→反干扰）；
2. M3 中**手工特征 vs 深度学习**的同图对比（前沿性）；
3. M3 检测的 **SNR 墙仿真与理论精确吻合**（理论与仿真互证）；
4. M4 的**精准干扰增益 ≈ 20 dB**，等于跳频处理增益 `B_tot/B_ch`（物理自洽）；
5. M5 的 **Q-learning 自适应跳频**：稳态可用度 0.999 vs 基线跳频 0.68（RL 前沿）；
6. M5 的**惯导一致性检测**在 −6 dB 即可检欺骗，优于功率/相关峰路线（#11）；
7. 全流程含**真实信道损伤**，结果非理想化。

**答辩需主动说明的简化**（避免被问住）：
- 仿真为合成信号，非 #1/#2 的实测数据集；合成信号更干净，识别率高于文献属正常；
- CNN 为 numpy 轻量实现（无 GPU/PyTorch），用于体现路线差异而非追求 SOTA；
- 多径为抽头延迟线近似（非射线追踪）；三类链路各自基带建模（实际载频不同）。
