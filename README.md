# 低空无人机信号特征 —— 仿真与报告支撑工程

> 电子对抗课程大作业（方向 10「低空无人机信号特征」，难度系数 1.0）的仿真代码。
> 主线：**一套信号特征，支撑对抗三线** —— 特征分析是"认知"，特征用于对抗是"利用"。

## 一句话简介

对低空无人机**遥控（FHSS+GFSK）/ 图传（OFDM）/ 导航（GNSS C/A）**三类链路
进行真实化建模与多域特征提取，并用同一套特征贯穿**电子侦察 → 电子干扰 → 电子反干扰**
三大部分，最后用指标闭环验证"一套特征支撑三线"。

## 模块结构（M1–M6）

| 模块 | 内容 | 关键结果 |
|---|---|---|
| `part1_M1_信号建模` | 三类链路基带建模 + 真实信道损伤（CFO/多普勒/相噪/IQ 不平衡/非线性/时变多径） | 时域/时频/功率谱 3 图 |
| `part2_M2_信号特征分析`（选题主体） | 时/频/时频/循环平稳/调制域多域特征 → 特征库 | 3 信号×16 维，三类完全可分 |
| `part3_M3_电子侦察` | 信号检测（ED/CFD）+ 链路识别（手工特征 vs 谱图 CNN） | ED 的 SNR 墙与理论吻合；识别率–SNR 曲线 |
| `part4_M4_电子干扰` | FHSS 跟随式干扰 + GNSS 欺骗/压制（蒙特卡洛 GFSK 实测） | 精准干扰增益 ≈ 19.7 dB |
| `part5_M5_电子反干扰` | Q-learning 自适应跳频 + 混沌跳频 + 惯导辅助抗欺骗 | RL 可用度 99.9% vs 基线 68% |
| `part6_M6_闭环评估` | 汇总各模块指标（自动读取 metrics.json），生成闭环图/总表 | 三线效能一张总表 |

## 主要结果速览

| 线 | 指标 | 数值 |
|---|---|---|
| 特征底座 | 跳频图案提取精度 | 12.7 kHz（信道间隔 159 kHz）|
| 侦察 | 弱信号检测灵敏度增益 | CFD 优于 ED 5.0 dB（ED 存在 −5.9 dB SNR 墙）|
| 侦察 | 链路识别 @-12 dB | 手工特征+RF 92.9% / CNN 60.0% |
| 干扰 | 精准干扰增益 | 19.7 dB ≈ 跳频处理增益 20 dB |
| 反干扰 | 自适应跳频可用度 | 99.9%（基线 68.3%）|
| 反干扰 | 抗欺骗定位误差 | 30 m → 2.3 m（惯导辅助）|

## 环境与运行

```
Python 3.10+  依赖：numpy / scipy / matplotlib / scikit-learn / pandas
cd 作业代码
python part1_M1_信号建模/run_part1.py   # 依序运行 M1→M6，每模块独立可跑
...
python part6_M6_闭环评估/run_part6.py   # 需要 M2–M5 先跑过（读取 metrics.json）
```

运行后图表自动保存到各模块 `figures/`；`M1` 额外支持 `--show` 弹出预览窗口；
依赖见各模块 `requirements.txt`（M1–M3 提供，其余模块依赖一致：numpy / scipy / matplotlib / scikit-learn / pandas）。
